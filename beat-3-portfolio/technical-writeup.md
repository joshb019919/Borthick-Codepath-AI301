## Limitations and what's next

This toolkit doesn't really take that much time off my plate 
as a software engineer or data scientist and has little, if 
any, bearing on whether or not I'll get a job in my field. 
It's just for helping gate commits into GitHub repositories, 
which will hopefully help show future employers that I'm 
skilled, fast, and active. However, it could probably have an 
automated pipeline tool that does all the skills, updates 
whatever it's to work on, and prepares submissions for claim 
comment, commit comment, and PR. It would put all these into 
a file or files for me to review, and I could say yay or nay 
to make it actually happen. It would thoroughly speed up my 
overall process, though it puts me more as an AI agent 
manager than a software engineer or data scientist.
